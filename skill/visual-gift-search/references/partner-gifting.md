# partner-gifting.md — 伴侣送礼判断方法

本文件将视频资料蒸馏为自然语言判断方法，供候选选择阶段调用。所有结论均有来源视频支持，来源编号见 references/source-index.md。冲突观点保留条件化结论，不强行统一。

## 一、明确愿望与弱兴趣信号

### 核心判断顺序

1. 先找「明确心愿」：用户文字中是否说明 TA 主动、反复、具体表达过获取意图。
2. 区分获取意图与审美表达：「想要/想买/帮我抢/等我攒钱」是获取意图；「好看/厉害/挺帅」是审美表达，不构成心愿。
3. 单次提及不计入明确心愿。需≥2 次主动提及，或 1 次明确「想要」+ 1 次相关行为（搜索、加购物车、试戴、收藏）。
4. 无明确心愿时，看「稳定兴趣」：同一品类是否在多处/多张图重复出现（≥2 处证据）。
5. 仅单次出现的弱线索不计入稳定兴趣，只作备查。

### 合适的表达方式

- 明确心愿：优先满足该款，不做创意替代。若候选库无该款，说明缺口，不强推替代品。
- 稳定兴趣：送该兴趣的周边配件或延伸表达，比送核心装备更安全。
- 审美欣赏：仅作风格参考，用于匹配候选的审美调性。

### 容易失败的方式

- 把单次「挺帅」当心愿，直接送该款。
- 把审美欣赏当购买意图，强行购买对方只打算看看的物。
- 把单次弱线索当稳定兴趣，据此推荐。

### 例外条件

- 若用户本身就是该兴趣圈层内行，且明确知道对方想要的型号，可直接送核心装备（资料未直接覆盖，产品原则补充）。

### 来源

V1（区分「很少喷香水」与「已有喷香水习惯」两套方案）、V7/V8（送周边配件而非核心装备）、V14（剃须刀/护肤品看对方使用习惯）、V16（投其所好原则）。

## 二、昂贵向往物与预算转换

### 核心判断顺序

1. 识别「昂贵向往物」：对方反复看/分享/收藏某高价物，但从不购买，常伴随「太贵了/再看看/以后再说」。
2. 默认按审美向往处理，不直接购买该昂贵物。理由：规格/版本/预算风险高，且可能打破对方「自己攒钱买」的计划。
3. 在预算内寻找该向往物的「相邻兴趣」延伸：
   - 同品牌延伸（如对方向往某品牌包→该品牌香线/小皮具）；
   - 同系列配件（如对方向往某款相机→该相机的配件或同品牌周边）；
   - 同风格平价款（保持审美调性，降预算）；
   - 同 IP 周边（如对方向往某 IP 大件→该 IP 小件）。
4. 用「相对价格」提升感知：在选定的小品类里买高品质款，使其价位高于对方该品类日常消费约 3 倍以上，更易被感知为「被放在心上」。

### 合适的表达方式

- 「这是你喜欢的那条线上的延伸，预算够不着大件时先收一件小物。」
- 表达层要呼应向往物，让 TA 知道你记得 TA 的向往。

### 容易失败的方式

- 强行攒钱买向往物的廉价仿款——审美不对、品质不够，更显敷衍。
- 直接买向往物本身但规格买错——昂贵物的规格门槛高，送礼方不懂行极易踩雷。
- 高开低走：第一次送很贵、之后越来越便宜，引发关系不安。

### 例外条件

- 若预算充足且能确认对方想要的具体版本/规格，可直接送向往物本身。

### 来源

V1（预算不够买大牌奢侈品时用香水替代，香水是同品牌感官延伸）、V7/V8（送周边配件而非核心装备）、V16（相对价格理论与小礼大送）。

## 三、实用性、纪念感与仪式感的平衡

### 核心判断顺序

1. 先判断场合仪式感强度：求婚向/第一个七夕/纪念日 ＞ 普通七夕与情人节 ＞ 520 ＞ 日常惊喜。
2. 仪式感强的节点：优先「可留存实物 + 表达层」（包装/贺卡/定制/限定款/纪念型实物）。
3. 日常惊喜：优先高频实用物或轻量体验，排面权重降低。
4. 两者之间（520、普通情人节）：需「看得见礼物 + 用心」，纯消耗品与纯虚拟物降级。
5. 实用与表达不是二选一：理想礼物是「实用打底 + 表达加成」。纯实用无表达=对付；纯表达不实用=自我感动。

### 合适的表达方式

- 仪式感节点：礼盒 + 隐藏文案 + 录音/手写贺卡 + 限定款。
- 日常：高频实用物 + 一句手写卡。
- 实用物 + 限定/纪念版：如情人节限定口味、纪念年份款。

### 容易失败的方式

- 仪式感节点送「看不着礼物」的纯服务/充值/消耗品（如年卡、补剂、虚拟皮肤）。
- 日常突然送重礼，造成对方关系压力。
- 纯 DIY 手工品对方用不上，只送礼方感动。
- 廉价定制（变色杯、印情侣照片的物件）社死。

### 例外条件

- 对方明确表达过「我就想要某个没实用价值的东西」时，投其所好优先于实用。
- 对方明确反感形式主义时，过度包装可能适得其反（资料无直接来源，产品原则补充）。

### 来源

V2、V3、V5、V7/V8、V12、V13（表达层组件）、V9（抗迭代高频）、V10（520 看不着礼物）、V14（自我感动 DIY、廉价定制）、V16（实用 + 情绪价值 + 小礼大送）、V20（游戏皮肤到不了夯）。

## 四、实体礼物与共同体验

### 核心判断顺序

1. 实体礼物默认适用：需要可被高频使用/佩戴形成记忆锚点，或需要承载表达层。
2. 共同体验适用：能让两人产生共同故事、催化感情；关系需要升温或日常互动不足；实体礼物已送过若干次需换形式。
3. 关键判断：体验是否有「可留存实物」？
   - 有可留存物（纪念酒 + 徽章、体验 + 拍立得、一起拼装可作摆件）：仪式感节点可用。
   - 无可留存物（纯服务、纯充值、纯虚拟）：仪式感节点降级，日常可用。

### 合适的表达方式

- 实体：贴身/贴肤物（香水、内裤、睡衣、贴身配饰）借感官与日常使用形成持续联想；高品质高频物（耳机、剃须刀、水杯）抗迭代。
- 体验：一起拼装、一起游戏、一起品酒、一起手工课、一起出行——附可留存纪念物。

### 容易失败的方式

- 纯体验无可留存物，在仪式感节点被评「看不着礼物、没心思」。
- 太小众的体验错配对方兴趣（如制冰机送给不喝冰的人）。
- 体验需双方档期对齐，落空即失效。
- 实体礼物规格买错、与已有物重复或更差。

### 例外条件

- 当体验足够贴合对方兴趣且自带纪念感时，可作为惊喜主礼直接出现，不必再配实体。
- 关系尚未亲密到贴身物尺度时，贴身物降级（产品原则补充）。

### 来源

V1（香水嗅觉记忆）、V7/V8（共同拼装/同玩/同饮）、V9（抗迭代高频物）、V10（充年卡/补剂看不着礼物）、V20（制冰机错配、内裤贴身记忆）、V14（印头像内裤尴尬）。

## 五、共同经历的表达

### 核心判断顺序

1. 共同经历的价值在于「让两人有更多故事」，而非礼物本身的物质价值。
2. 判断该经历是否需要双方协同（时间、技能、兴趣门槛）。
3. 共同经历适合关系需要升温、或日常互动不足、或已有足够实体礼物需要换形式时。
4. 不适合关系尚未稳定、双方档期难对齐、或对方明确偏好独处时。

### 合适的表达方式

- 附可留存纪念物的共同经历：拼完可作摆件、喝完留瓶与徽章、拍完留相纸。
- 在理由中点明「这是两人一起完成/一起经历的」，而非只强调物。

### 容易失败的方式

- 强行安排对方不感兴趣的活动当礼物。
- 共同经历无可留存物，事后无记忆锚点。
- 档期对不齐，礼物落空。

### 例外条件

- 若双方本就有共同兴趣，共同经历可作为日常惊喜的低成本高效果选项。

### 来源

V7/V8（乐高同拼当摆件、Switch 同玩、纪念酒同饮 + 徽章）。

## 六、未知规格风险

### 核心判断顺序

1. 列出候选所依赖的规格信息：型号、尺寸、色号、接口、口径、肤质、嗅觉偏好、版本、比例。
2. 判断这些规格是否可在当前流程内确认。
3. 按风险分级：
   - 高风险（买错不可用/浪费/尴尬）：护肤品肤质、香水味道、鞋码、戒指圈口、电子产品接口与生态、模型版本与比例、酒类口味。
   - 中风险（有通用兜底）：颜色（可选中性色）、尺寸（可选可调节）。
   - 低风险（规格影响小）：无明显规格依赖的物。
4. 高风险且无法确认：降级，仅在无更好选项时保留，理由中标注「需用户确认」。
5. 不得假装规格已知，不得用「应该适合」「大概率没问题」搪塞。

### 合适的表达方式

- 优先选不依赖该规格的候选。
- 必须选含未知规格的候选时，选有通用兜底的（中性色、通用接口、可调节尺寸）。
- 理由中如实标注「需确认 X」，说明买错后果。

### 容易失败的方式

- 盲送高风险规格物，买错后无法使用。
- 把「应该适合」当确认。
- 送对方已有强偏好的品类却不知其偏好（如已有固定香水习惯却乱送香水）。

### 例外条件

- 若用户明确提供了规格，或图中可清晰辨认规格，按已知处理。

### 来源

V1（墨镜颜色拿不准买黑色）、V15（香水选错味道落灰）、V16（避雷廉价定制变色杯）、V18（护肤品需了解肤质与抗老需求）。

## 七、热门礼物失效

### 核心判断顺序

1. 识别候选是否属于「不知道送什么就送 X」的兜底品类（如通用香水、通用花、通用大玩偶、钱包墨镜鞋子老三样）。
2. 判断场合：若场合本应有仪式感，兜底品类易被视为敷衍，降级。
3. 判断对方已有偏好：若对方在该品类已有强偏好/已有物，热门款易撞款或不如现有的，降级。
4. 判断专业雷点：若候选是对方核心专业领域的核心装备（非周边配件），送礼方不懂行，降级。
5. 判断自我感动/社死风险：纯 DIY 用不上、廉价定制印头像、印情侣照片——剔除。

### 合适的表达方式

- 热门款需附加「用心版」才成立：限定口味、定制徽章、隐藏文案、录音贺卡、手写信。
- 把热门款作为「稳妥项」之一，不作为唯一主推。

### 容易失败的方式

- 把香水当「不知道送什么」的兜底——被评「下下策/NPC/太常规」。
- 送老三样（钱包/墨镜/鞋子）无新意。
- 送对方已有且用惯的品类中更差的款。
- 送对方核心专业领域的入门级核心装备。

### 例外条件

- 热门款若附加充分表达层且规格匹配对方偏好，仍可成立。
- 对方明确表达过喜欢该热门款时，投其所好优先。

### 来源

V7/V8（钱包墨镜鞋子老三样没新意、不送核心专业领域）、V14（DIY 自我感动、印头像内裤尴尬）、V15（香水选错落灰）、V16（廉价定制社死、送更差款无效）、V20（香水下下策、游戏皮肤到不了夯）。

## 八、需要直接询问的情况

### 核心判断顺序

1. 判断是否存在「不澄清就必然选错」的关键歧义：
   - 该物品是 TA 已有，还是想要？
   - 这是 TA 的兴趣，还是偶然使用？
   - 规格未知且候选间不兼容（接口/尺寸/色号/口径）？
   - 场合是仪式感节点还是日常惊喜？
   - 关系亲密度是否到达贴身物/共同体验的尺度？
2. 若存在关键歧义，且澄清后推荐结果会显著不同，应直接询问。
3. 最多问一个问题，按优先级：规格歧义 ＞ 已有/想要歧义 ＞ 场合歧义 ＞ 兴趣确认。
4. 若在线流程不支持追问（单次调用），对歧义做最保守处理，并在理由中标注需用户注意的条件。

### 合适的表达方式

- 「为了不买错，我需要确认一件事：……」
- 只问一个问题，不连环追问。
- 不问可以通过视觉二次确认的问题。

### 容易失败的方式

- 存在关键歧义却继续猜，导致整单偏离。
- 为了凑流程而问无关问题。
- 连环追问，消耗用户耐心。

### 例外条件

- 若用户已提供具体品类 + 规格/型号/SKU 且锁定该款，转入直接商品搜索，不再询问。
- 若视觉证据充分、无关键歧义，直接进入候选选择，不询问。

### 来源

资料中「何时该直接询问」是盲区（所有视频均面向「不知道送什么」的迷茫用户，未覆盖该场景）。本节为产品原则补充，依据视觉证据稳健性与伴侣送礼失效模式归纳。

## 用户已有明确购买目标时的退出

当用户已提供具体品类 + 规格/型号/SKU 之一，且明确就是要这一个时：

- 不再做创意推荐，不做视觉个性化。
- 输出直接商品搜索方向，结束视觉个性化流程。
- 这是硬性退出条件，不因视觉线索丰富而改变。

来源：资料未直接覆盖（所有视频面向迷茫用户），产品原则补充。
