## 人工补充的产品原则（非视频来源）

以下原则不来自任何视频，依据产品需要与视觉证据稳健性补充，已在 SKILL 与 references 中标注：

- 明确心愿的判定阈值：≥2 次主动提及，或 1 次「想要」+ 1 次相关行为。
- 偶然入镜物品不计入稳定兴趣，仅作弱线索。
- 分享昂贵物品的三种含义（审美分享 / 心愿试探 / 购买咨询），默认按审美分享处理。
- 何时应直接询问：存在「不澄清就必然选错」的关键歧义时。
- 用户已有明确购买目标时的退出：转为直接商品搜索，不做创意推荐。
- 过度推断禁令：不从单张房间/穿搭照推断人格、消费能力、收入、性取向。
- 关系亲密度门槛：贴身物需关系足够亲密，否则降级。
- 资料盲区场合（求婚/毕业/异地恋见面/和解道歉/跨年）：不虚构结论。
